# eda-ml

Решение задания «EDA и машинное обучение» вступительного испытания в магистратуру ИТМО «Искусственный интеллект» (AI
Talent Hub).

Репозиторий содержит разведочный анализ данных, выводы по данным и baseline-модель по датасету, выдаваемому на экзамене.

> **Статус: подготовка окружения.** Задание и датасет ещё не получены, поэтому разделы с
> постановкой задачи, анализом, моделью и результатами будут заполнены во время выполнения
> задания — по фактически полученным данным и фактически измеренным метрикам.

## Окружение

- Python 3.13 (`.python-version`)
- Менеджер зависимостей и окружения — [uv](https://docs.astral.sh/uv/); `uv.lock`
  зафиксирован в репозитории
- Основные библиотеки: pandas, numpy, pyarrow, scikit-learn, scipy, matplotlib, seaborn
- Dev-зависимости: jupyter, ipykernel, pytest, ruff

## Воспроизведение

```powershell
uv sync                 # создать .venv строго по uv.lock
uv run jupyter lab      # запустить ноутбуки
uv run pytest           # тесты (если добавлены)
uv run ruff check .     # линтер
```

## Структура репозитория

```
src/eda_ml/     переиспользуемый код (загрузка, очистка, признаки, обучение)
notebooks/      разведочный анализ и baseline (создаётся при выполнении задания)
tests/          тесты (создаются при необходимости)
AI_USAGE.md     журнал использования AI-инструментов
README.md       описание решения
```
