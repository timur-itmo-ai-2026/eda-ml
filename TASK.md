# Легенда

Вы - аналитик в команде клиентского опыта крупного банка. Банк получает поток жалоб, которые регулятор пересылает для
обязательного ответа, и запускает фичу «Приоритет обращения»: система оценивает вероятность того, что по обращению
придётся выплатить компенсацию, и подсказывает оператору, какие жалобы эскалировать сразу, а какие можно закрыть
стандартным разбором. Все задания ниже - реальные шаги подготовки этого запуска: сначала понять данные, затем проверить,
можно ли на них строить оценку риска, и решить, как запускать фичу. Вам выданы два учебных датасета обращений,
подготовленные на основе открытой базы Consumer Complaint Database (CFPB, США):

- complaints_train.csv - обучающая часть, включая relief_granted. На Google Drive выдаётся архивом
- complaints_train.csv.zip (~1.8 ГБ; распакованный CSV - около 7.7 ГБ), распакуйте его перед работой;
- complaints_test.csv - отложенная часть, без relief_granted;
- sample_submission.csv - пример файла с предсказаниями. Продукт, подпродукт, тип проблемы, компания, штат, ZIP, канал
  подачи, даты получения и передачи в компанию - плюс сырое текстовое поле Consumer.Complaint.Narrative с описанием
  ситуации словами самого потребителя. Таргет relief_granted равен 1, если компания закрыла обращение с денежной или
  неденежной компенсацией, и 0 иначе. Записи обезличены, а технические идентификаторы и часть значений преобразованы.
  Все расчёты выполняйте только по выданным файлам; внешняя база может не совпадать с учебной версией. Данные сырые:
  пропуски, дубликаты, разнобой в написании категорий, несколько форматов дат, мусорные значения, шаблонные массовые
  подачи одного и того же текста. Отложенная часть - это последние месяцы наблюдений, то есть будущее относительно
  обучающей. Уровни A и B обязательны для всех. Уровень C (продвинутый) - в первую очередь для поступающих на программу
  «Искусственный интеллект», уровень P (продуктовый) - для тех, кто приоритетно поступает на программу «Управление
  ИИ-продуктами / AI Product». Использование AI-инструментов разрешено. Ориентир по времени: A - 15 мин, B - 45 мин,
  оставшийся час распределяйте между C и P с учётом вашей целевой программы.
